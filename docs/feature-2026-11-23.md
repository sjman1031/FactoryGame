### "현재 코드 기반"의 의미 — 게임과 같은 지형이 나온다
미리보기는 생성 로직을 새로 만들지 않고 게임 코드를 그대로 부른다.
- 높이: `ChunkGenerator.Generate` / 메시: `ChunkInstance.BuildMesh` / 광맥: `ChunkGenerator.GetOreDistribution`
- 시드·평지 중심·생성 순서: `WorldPreGenerator.SpawnPoint`, `WorldPreGenerator.BuildCoordList`
- 순서도 `WorldStreamingManager.Load`와 같다(위치 → 메시 → 활성화).

같은 시드와 맵 크기면 실제 새 게임과 같은 지형이 나온다. 미리보기가 바꾸는 것은 **표시뿐**이다.
- 청크마다 64×64 텍스처(Point 필터)를 칠해 `MaterialPropertyBlock`으로 넣는다. 머티리얼을 복제하지 않는다.
- 픽셀 (x, z)는 정점 (x, z)에서 시작하는 칸이다(`BuildMesh`의 UV가 x/size, z/size).
- 광맥 모드: 칸마다 확률이 가장 높은 광물의 색으로 칠하고, 확률이 높을수록 진하게 한다. 광물이 없는 칸은 높이색을 어둡게 한다. 색 목록에 없는 광물 id는 id 해시로 색을 정한다(테이블에 광물을 추가해도 보인다).

### 조작
| 키 | 동작 |
|---|---|
| Space | 같은 시드로 다시 생성 |
| R | 새 무작위 시드로 다시 생성 |
| V | 표시 전환 (높이 → 광맥 → 단색) |
| P / N | 일시정지 / 일시정지 중 한 단계 |
| F | 남은 청크 한 번에 생성 |
| G | 화면 정보 숨기기 |
| 우클릭 드래그 · WASD · Q/E · Shift · 휠 | 카메라 |

### 설계 메모
- **세이브를 거치지 않는다.** `SaveSystem`·`world.bin`을 쓰지 않으므로 세이브 슬롯을 건드리지 않는다. 그래서 MainScene과 달리 LoadingScene에서 시작하지 않아도 된다.
- **싱글톤 매니저를 쓰지 않는다.** `WorldStreamingManager`는 SaveSystem에서 청크를 읽으므로 재사용하지 않았다. 미리보기는 독립 컴포넌트라서 게임 씬의 수명 구조(W13·K6)와 엮이지 않는다.
- **프리팹은 선택 사항이다.** `_chunkPrefab`을 비우면 `ChunkInstance`를 코드로 붙이고 Standard 머티리얼을 만든다. 게임의 Chunk 프리팹을 넣으면 그 머티리얼에 텍스처만 덮어쓴다(`_MainTex`, URP용 `_BaseMap` 둘 다 설정).
- **화면 정보는 IMGUI(`OnGUI`)로 그린다.** 디버그 도구라서 Canvas·TMP 구성 없이 바로 보이게 했다.
- 청크 사이에 **1칸 틈**이 보이는 것은 미리보기 버그가 아니라 현재 지형 코드 그대로다(K1, 사용자 결정 대기). 미리보기로 K1을 눈으로 확인할 수 있다.

## 5. 씬 구성 — `Assets/Scenes/TerrainPreviewScene.unity` (사용자가 만듦, 2026-11-23 커밋)

```
TerrainPreviewScene
├ Directional Light       회전 (50, -30, 0) 정도. 경사가 그림자로 보이도록
├ Main Camera             태그 MainCamera + PreviewFlyCamera
│                          위치는 아무 데나 — TerrainPreview가 시작할 때 맵 전체가 보이게 옮긴다(_autoFrameCamera)
└ [TerrainPreview]        TerrainPreview
                            _seed            0 (MainScene의 새 게임과 비교하려면 같은 시드)
                            _mapWidth/Height 8 × 8   (게임 기본값은 16 × 16)
                            _chunksPerStep   1,  _stepInterval 0.05,  _riseDuration 0.4
                            _chunkPrefab     비워도 됨 (있으면 게임의 Chunk 프리팹)
                            _material        비워도 됨 (Standard 자동 생성)
```
- EventSystem·Canvas 필요 없음(화면 정보는 OnGUI).
- Build Settings에 넣을 필요 없음. 에디터에서 이 씬을 열고 바로 Play.
- 기즈모를 Game 뷰에서 보려면 Game 뷰 오른쪽 위 **Gizmos** 버튼을 켠다.
- 천천히 보고 싶으면 `_stepInterval`을 0.3 정도로, 빨리 보려면 `_chunksPerStep`을 늘린다.
