### 설계 메모
- **씬 이름 오류는 `Fail()`을 쓰지 않는다.** `Fail()`의 재시도는 "이 슬롯을 새 게임으로 덮어쓰기"다. 설정 오류는 재시도해도 고쳐지지 않고 세이브만 날아간다. 그래서 "알리고 보존" 원칙에 따라 알리기만 한다.
- **입력(BuildingHotbar)과 배치(BuildingPlacer)를 나눴다.** 나중에 건설 메뉴 UI를 만들면 Hotbar만 바꾸거나 함께 쓰면 되고, Placer는 그대로 둔다.

## 4. 씬 구성안 (S4)

### 흐름
LoadingScene(index 0) → `SaveSystem.Initialize` → MainScene(index 1). SaveSystem은 로딩 씬에서만 생기므로 **Play는 항상 LoadingScene에서 시작**한다.

### LoadingScene
```
Main Camera
EventSystem
[Loading]  LoadingSceneController(_gameSceneName=MainScene, _generator, _ui, _saveSlot) + WorldPreGenerator
Canvas     LoadingUIController → ProgressBar(Slider), StatusText/PercentText(TMP), ErrorPanel(꺼 둠)/ErrorText/RetryButton
```

### MainScene
```
Directional Light, EventSystem
[GameBootstrapper]        → 매니저 4개 연결
[InputManager] [TickManager] [WorldStreamingManager(_player, _chunkPrefab)] [PlayerMovementManager]
                          ← 매니저는 각각 루트 (DontDestroyOnLoad는 루트에만 적용, 중복 시 오브젝트째 Destroy)
[SaveController]          (_player, _catalog)
[BuildingSystem]          BuildingCatalog(프리팹 4종) + BuildingPlacer(레이어·프리뷰 머티리얼·gridSize 1) + BuildingHotbar(_placer, _slots)
Player                    CharacterController + PlayerController(_cameraArm)
 └ CameraArm
    └ Main Camera         태그 MainCamera
```

### 프리팹
| 프리팹 | 구성 |
|---|---|
| Chunk | MeshFilter + MeshRenderer(지형 머티리얼) + MeshCollider + ChunkInstance (레이어는 이제 코드가 Ground로 지정) |
| Miner / ConveyorBelt / Manufacturer / Storage | 각 건물 스크립트 + Collider. 피벗은 바닥 중앙, 크기는 1×1×1 안. Manufacturer는 `currentRecipe` 연결 |

### 프로젝트 설정
- Tags & Layers에 `Ground`, `Building` 추가.
- Build Settings: LoadingScene(0), MainScene(1).

## 5. 에디터에서 사용자가 할 일
1. Tags & Layers에 `Ground`, `Building` 레이어 추가.
2. 4절대로 씬과 프리팹 구성. `BuildingHotbar._slots`에 Miner·Belt·Manufacturer·Storage 순서로 넣으면 1~4키.
3. BuildingPlacer를 레이어를 추가하기 **전에** 붙였다면 인스펙터 ⋮ › Reset을 하거나 마스크를 직접 지정.
4. `BuildingHotbar.cs.meta`는 Unity가 만든다 → 커밋. (이전에 생성된 `.meta` 11개는 이 수정과 함께 커밋했다)

## 6. 고치지 않은 것
- **K6 씬 재진입**: DontDestroyOnLoad 매니저(WorldStreamingManager)가 이전 씬의 Player를 참조하는 문제. 리뷰 로드맵 15번에서 W2·W3·W12·W13(수명·소유권)과 묶여 있다. 매니저 수명 구조를 바꾸는 일이라 W13 결정과 함께 진행한다. 지금은 메뉴 → 게임 → 메뉴로 다시 들어가는 흐름이 없어서 증상이 나타나지 않는다.
